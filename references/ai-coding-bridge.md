# AI Coding 衔接指南

只有用户需要开发或让 AI Coding 实现时才使用本指南。

技术内容是业务需求之后的可选附录。用户只要求写需求单时，不输出本部分。

## 衔接顺序

```text
业务需求确认
→ 项目现状分析
→ 技术和架构选择
→ 模块与数据设计
→ 分阶段开发任务
→ 测试与验证
→ 需求与实现结果对照
```

## 规划要点

- 优先查看已有技术栈、目录结构、组件和代码规范。
- 不为简单功能引入不必要的框架或依赖。
- 业务语义和范围未确认前，不做技术选型或任务拆解。
- 说明模块职责、复用边界和数据流向。
- 要求 AI 分阶段实现，每阶段完成后验证，不一次性生成大量代码。
- 为关键逻辑补充单元测试、接口测试或页面验证。
- 交付前检查实现是否覆盖需求、边界和验收标准。
