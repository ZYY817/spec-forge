# 输出对象、格式与附件

## 输出对象

根据用户目的选择一种主要版本：

| 目的 | 重点 |
|---|---|
| 快速同步 | 背景、结论、待办和关键提醒 |
| 工作需求单 | 背景、需求详情、位置、规则和验收 |
| 开发测试版 | 在工作需求单基础上补充边界、数据和实现注意事项 |
| AI Coding 规划 | 业务需求之后补充项目分析、架构、模块、任务和验证 |

不要没有必要地同时生成多套版本。用户指定格式时优先遵循用户习惯；用户未指定时，默认使用易复制的 Markdown。

## 图片和附件

- 先说明图片或附件中的直接事实，再说明基于它的判断。
- 图片用于说明页面位置、现状或交互时，在对应章节附近引用，不要集中堆在文档末尾。
- 多张图片用“图 1、图 2”或用户已有名称区分，并写清每张图支持哪个结论。
- 图片只是参考时，不要把图片中暂时显示的内容直接当成完整业务规则。
- 图片是验收依据时，写出需要验证的具体区域或行为。
- 对旧需求、会议纪要或聊天记录，提取有效结论，不要把原文整段复制进需求单。

## 格式选择

默认生成 Markdown，便于复制到项目管理工具、文档工具或 Codex。只有用户明确需要 Word、表格文件或其他格式时，才生成对应文件。
